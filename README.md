# Student Performance Analytics System Using MongoDB

## Project Description

This project is a MongoDB-based application developed to store,
process, analyze, and visualize student performance data.

The system stores 5,000 student records in MongoDB and provides
data processing and analysis through Python and a Streamlit dashboard.

## Technologies Used

- Python
- MongoDB
- PyMongo
- Pandas
- Streamlit
- Plotly
- MongoDB Aggregation Framework

## Main Features

- Store 5,000 student records in MongoDB
- Create, Read, Update, and Delete operations
- Student search
- Department filtering
- Semester filtering
- Student performance analysis
- Department-wise analysis
- Placement analysis
- Average CGPA analysis
- Top 10 student analysis
- Interactive Streamlit dashboard

## Database

Database Name:

student_analytics

Collection Name:

students

## Student Data Fields

- Student ID
